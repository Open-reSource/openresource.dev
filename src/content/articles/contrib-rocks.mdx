<p class="lead">[contrib.rocks](https://contrib.rocks/) is an online tool that generates an image of the top contributors of a GitHub repository. You can embed it in any website or Markdown file, including your README file.</p>

It's completely free and maintained by Suguru Inatomi, a.k.a. [lacolaco](https://github.com/lacolaco). The source code is available on GitHub:

<ShowcaseGitHubRepo env="lacolaco" repo="contributors-img" img="1529180" />

This service gives a visual representation of the top contributors of any GitHub repository.

Generating such an image of your GitHub repository top contributors is a great way to show the activity of your GitHub repository, encourage people to contribute and celebrate your top contributors.

## How to Use

Usage is pretty straightforward:

1. Go to https://contrib.rocks/
2. Enter a GitHub repository (e.g., `open-reSource/openresource.dev`)

And that's it! You'll get the image representing the top contributors of the GitHub repository you entered.

Then, you can click on the "Get Image URL!" button to get the Markdown code to embed the image in your README file for instance.

```md
<a href="https://github.com/open-reSource/openresource.dev/graphs/contributors">
  <img src="https://contrib.rocks/image?repo=open-reSource/openresource.dev" />
</a>

Made with [contrib.rocks](https://contrib.rocks).
```

The first part of the generated Markdown code is actually HTML. You can use it to embed the image in any website or Markdown file.

Some parameters can be added to the URL to customize the image:

- `max={number}`: Max contributor count (100 by default)
- `columns={number}`: Max columns (12 by default)
- `anon={0|1}`: Include anonymous users (false by default)

Add `&max=10&columns=2` to the image URL `https://contrib.rocks/image?repo=godotengine/godot` and you get the following image with only the top 10 contributors and 2 columns:

```md
<a href="https://github.com/godotengine/godot/graphs/contributors">
  <img src="https://contrib.rocks/image?repo=godotengine/godot&max=10&columns=2" />
</a>

Made with [contrib.rocks](https://contrib.rocks).
```

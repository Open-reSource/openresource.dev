## How LinkedIn carousels work

A LinkedIn carousel is a series of images or slides that you swipe through. It's a great way to share information in a visually appealing format. You can use one to present your open-source project, share tips, or even tell a story.

There's no real creator tool for LinkedIn carousels, so you have to create them yourself.

**A LinkedIn carousel is a PDF file.** Create a PDF with multiple pages, and each page becomes a slide. Upload the PDF to LinkedIn, and it converts it into a carousel.

1. On LinkedIn, click on the "+ Create" button.
2. Select "Start a post".
3. Click on the "+" icon, and "Add a document".
4. Select your PDF file, choose a document title, and LinkedIn will convert it into a carousel.

## The Idea

**If it's just a PDF file, why not code it?** We can create a simple HTML file with multiple slides, then convert it into a PDF file. And that's what we did!

We already use a great tool for presentations: [Slidev](https://sli.dev/).

Slidev is a presentation tool based on Vue.js. It lets you create beautiful slides with Markdown and code, and it can export them as a PDF file. It's an open-source project under the MIT license.

## How to Code LinkedIn Carousels

It's simple. First, create a new Slidev project with this command:

```sh
npm init slidev@latest
```

This creates a new Slidev project in the current directory. Then open the project in your code editor and start customizing the slides.

You'll notice that the default Slidev theme doesn't suit LinkedIn carousels, because its slides are wide, in a 16:9 ratio. You'll need to customize the theme.

In the `slides.md`, add these properties to the frontmatter:

```json
---
aspectRatio: "3/4"
canvasWidth: 800
```

Install `playwright-chromium` as a dev dependency, and export your slides as a PDF file:

```sh
npm install -D playwright-chromium
npm run export
```

And voilà, you get a nice `slides-export.pdf` that you can use as a LinkedIn carousel!

### How to Use the Theme

To use the theme, install it as a dev dependency:

```sh
npm i -D slidev-theme-linkedin-carousel
```

Then add this frontmatter to your slides:

```md
---
theme: linkedin-carousel
---
```

For more information on how to use the theme, check out the [README](https://github.com/Open-reSource/slidev-theme-linkedin-carousel).

The `example.md` file in the repository is a good starting point for your own LinkedIn carousels. From there, customize the slides to your liking, and even use custom components to make them more impactful.

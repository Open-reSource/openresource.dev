# Code of conduct

## Our standard

We want this project to be a place where people can work on the code without dreading the thread. In the issue tracker, pull requests, discussions and any space that represents the project:

- Be respectful. Disagree with the idea, not the person.
- Assume good faith, and ask before you assume otherwise.
- Keep the discussion on the project. No harassment, insults, personal attacks, or sexualized language or imagery.
- Don't publish other people's private information.

## Enforcement

Maintainers can edit or remove comments, close threads, and block people who don't follow this code of conduct. They explain the decision when they can.

## Reporting

Write to conduct@example.org. Only NAME and NAME read this inbox. If your report is about one of them, write to NAME at other@example.org instead. We keep reporters' identities private.

## Scope

This code of conduct applies in project spaces, and when someone represents the project in public.
